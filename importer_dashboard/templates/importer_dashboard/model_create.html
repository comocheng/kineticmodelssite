The folder Prometheus makes

  • mechanism.txt your mechanism file
  • thermo.txt your thermo file (none if the thermo is in the mechanism)
  • transport.txt your transport file, if any
  • SMILES.txt your SMILES.txt, or an empty one
  • source.txt the citation, the DOI, where the files come from, and their original names
  • import.sh written by Prometheus

The files are kept byte for byte. import.sh sets no port: the Importer gives each run a free one.
