What happens next

  1. 1
    A draft The files go into a new branch of RMG-models {{ base_branch }} on this server.
  2. 2
    Check files The Importer reads them as an import would.
  3. 3
    The import It starts when the check passes. You confirm the species on the Importer page.
  4. 4
    A pull request When the job is complete, open it from the job page with your GitHub account. After the merge, the model goes into the database.
